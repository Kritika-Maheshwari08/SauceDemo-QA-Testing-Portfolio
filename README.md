# SauceDemo QA Testing Portfolio

## Project Overview

This repository contains a Manual Testing project conducted on the SauceDemo E-Commerce web application. The project covers test scenario creation, test case design, execution, and validation of key application functionalities.

**Application Under Test:** https://www.saucedemo.com/

## Modules Tested

* Login
* Products
* Product Sorting
* Shopping Cart
* Checkout
* Navigation

## Testing Performed

* Functional Testing
* UI Testing
* Positive & Negative Testing
* Smoke Testing
* Regression Testing

## Project Files

### SauceDemo_TestCases.xlsx

Detailed test cases with test steps, test data, expected results, actual results, and execution status.

### Test_Scenarios.xlsx

High-level test scenarios and QA documentation templates.

### Screenshots

Screenshots captured during testing and validation.
